Page 2 of 3 · WorkflowHow each pillar runs and which blocks it needs

Each pillar is a six-step line. Every step has an owner.

Owners are functional blocks, not job titles: a human on the team, a digital agent, the partner, or a contractor paid per deliverable. Humans keep the thesis, the relationship and the price. Agents run everything repeatable.

HUMANFounder and core team. Hosts, decides, prices, closes.
AGENTDigital agent on the Claude Agent SDK with the house skills. Research, production, publishing, follow-up, finance.
PARTNERPartner organisation: data, cohorts, introductions, China invoicing.
CONTRACTOREditor, designer, event producer, community coordinator. Paid per deliverable.
