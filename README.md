# Fragrant Hill Studio

Editorial house on tech, culture, industry and human-centric content. Registered in Stockholm, active in Europe and China.

## Repository map

- `framework/` — the three-page executive framework in English and Chinese (`p1-architecture-{en,zh}.html`, `p2-monetisation-{en,zh}.html`, `p3-encore-{en,zh}.html`), a reading summary in `00-summary.md`, research notes with sources in `framework/research/`, and the earlier five-document draft in `framework/archive/`.
- `skills/` — reusable Claude skills for recurring work: English coaching format, design system, sponsorship proposals, content pipeline.
- `interviews/` — interview preparation material.

## Editing the framework

Each document in `framework/` is self-contained. Edit one file and republish it; the others do not change. All six pages are generated by `framework/build/build_pages.py` from one content model with English and Chinese strings; edit the text there and run `python3 framework/build/build_pages.py`. Published page links live in `framework/build/links.json`.
