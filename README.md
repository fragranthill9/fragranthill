# Fragrant Hill Studio

Editorial house on tech, culture, industry and human-centric content. Registered in Stockholm, active in Europe and China.

## Repository map

- `framework/` — the three-page investor framework (`p1-system-architecture.html`, `p2-workflow.html`, `p3-encore-programme.html`), a reading summary in `00-summary.md`, research notes with sources in `framework/research/`, and the earlier five-document draft in `framework/archive/`.
- `skills/` — reusable Claude skills for recurring work: English coaching format, design system, sponsorship proposals, content pipeline.
- `interviews/` — interview preparation material.

## Editing the framework

Each document in `framework/` is self-contained. Edit one file and republish it; the others do not change. `p2-workflow.html` is generated by `framework/build/build_p2.py` (run `python3 framework/build/build_p2.py`); edit the workflow data in that script, or edit the HTML directly.
