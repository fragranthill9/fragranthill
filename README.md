# Fragrant Hill Studio

Editorial house on tech, culture, industry and human-centric content. Registered in Stockholm, active in Europe and China.

## Repository map

- `framework/` — the partnership framework: five separate HTML documents (benchmark, architecture, operating system, Encore proposal, partner pitch), a reading summary in `00-summary.md`, and research notes with sources in `framework/research/`.
- `skills/` — reusable Claude skills for recurring work: English coaching format, design system, sponsorship proposals, content pipeline.
- `interviews/` — interview preparation material.

## Editing the framework

Each document in `framework/` is self-contained. Edit one file and republish it; the others do not change. `03-operating-system.html` is generated by `framework/build/build_os.py` (run `python3 framework/build/build_os.py`); edit the workflow data in that script, or edit the HTML directly.
