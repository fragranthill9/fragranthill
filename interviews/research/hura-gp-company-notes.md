## 2. Technical disclosures (all vendor-claimed)
- HURA remote racing system (Intedigo): 1080p@60 Hz video; glass-to-glass video latency < 80 ms; control
  latency < 10 ms (2026 WAIC/Fibocom materials).
- HURA PARK 2025 materials: "system latency within 8 ms" (likely control-loop figure), 5G + local private
  network (本地专网), haptic feedback; 1:8-scale electric cars; 2025-03 article: 90 ms video, 1,500 km range.
  intedigo.com: 100 km/h top speed for the "HURA 5G 远程实景赛车".
- Architecture (press release): vehicle uplinks live track video + vehicle status + operating data to the
  cockpit; cockpit downlinks control commands -> "closed-loop teleoperation". Fibocom FM160 5G module
  (Qualcomm Snapdragon X62, SA/NSA, 3GPP R16, SA DL 2.5 Gbps / UL 900 Mbps) provides cellular link; press
  stresses uplink bandwidth + link stability as the key constraint for embodied-AI teleoperation.
  Fibocom quote: 陶曦 Tao Xi, VP Wireless Solutions BG, Fibocom.
- Video codec, control protocol, edge compute, game engine: NOT disclosed in anything found.
- Telecom operator (China Mobile/Unicom/Telecom), Huawei, chip vendors: NOT named in any source found.
  Only named tech partner = Fibocom (广和通, SZ-listed module maker). Venue partner = 上海国际汽车城 (Shanghai
  International Automobile City, Anting). Sports bodies = 中国体育用品业联合会运动空间专委会, WPC, Phygital International.
- Patents: no patents found under 中智蓝途 / 互然焕速 / Intedigo / HURA (Google Patents not reachable; search
  results empty). Unverified absence.
- HURA Europe concepts: Phygikart (track), Phygicross (off-road), Phygiwave (powerboat), "all prototyped and
